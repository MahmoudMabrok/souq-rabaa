# قالب سوق الرابعة — بورصة السادات

صفحة HTML لتعديل أسعار الخضار والفاكهة ثم تصدير الإعلان كصورة PNG.

## الموقع الباشر

https://mahmoudmabrok.github.io/souq-rabaa/

## الريبو

https://github.com/MahmoudMabrok/souq-rabaa

## الاستخدام

1. افتح الموقع.
2. عدّل الأسعار والنصوص من الجانب.
3. اضغط **تصدير كصورة PNG** وانشر على فيسبوك.

الأسعار تُحفظ محلياً في المتصفح (لا ترفع للسيرف).

## تفعيل GitHub Pages (إن لم تشتغل تلقائياً)

Settings → Pages → Source: **GitHub Actions**  
أو: Deploy from a branch → `main` / `/ (root)`
